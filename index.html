ABOUT

CLASSIC STRIKE is an original single-player tactical shooter that runs entirely in your browser: native WebGL 2, vanilla JavaScript, no engine, no frameworks, no server.

All maps, textures, models and sounds are original and generated procedurally at load time. Two fictional factions — INSURGENTS and TASK FORCE — fight over bomb sites with computer-controlled squads.

Current build: Phase 2 (weapons, bots, combat, sound). See README for the roadmap.
